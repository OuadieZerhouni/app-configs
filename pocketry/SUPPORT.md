# Pocketry — Help & feedback

**Where are the games?**
Pocketry plays GBA, GBC and GB game files that you already have. No commercial games are included and none can be downloaded in the app. Two free open-source homebrew games (Tobu Tobu Girl and Tobu Tobu Girl Deluxe, by Tangram Games) are on your shelf from the start.

**How do I add a game?**
Tap **Add games** on the shelf and pick .gba, .gbc, .gb or .zip files in the Files app. You can also tap a game file in Files or in a download list and choose **Open in Pocketry**. If Pocketry says a file isn't a game, the file is damaged or is a different format.

**Where are my saves, and can I lose them?**
In-game saves are in Files → On My iPhone → Pocketry → Saves, as standard .sav files. Each time the game saves, before each save-state load and before each import, Pocketry keeps a copy in the save history. Open a game's ⋯ menu → **Saves and states** → **Restore** to roll back. Removing a game from the shelf keeps its saves unless you tick the box.

**What is the difference between a save and a save state?**
An in-game save is made by the game itself (its save menu). A save state is a snapshot Pocketry takes of the whole game at any moment, from the pause menu. Use both; loading a state never deletes an in-game save.

**How do I move my progress to another phone or another emulator?**
Settings → **Export all saves and states** makes one backup file; on the other phone use **Restore from a backup**. A single .sav can be exported from a game's Saves screen and read by other emulators.

**My controller does not work, or the buttons are wrong.**
Pair the controller in iOS Settings → Bluetooth first. Then Settings → **Controller** shows it as connected and lets you change every button. **Reset to defaults** undoes it.

**There is no sound.**
Pocketry follows the silent switch by default. Turn the switch off, or turn off **Respect the silent switch** in Settings. Check **Volume** there too.

**I bought Pro but the skins are locked.**
Open any locked skin and tap **Restore purchase**. You need to be signed in with the Apple Account that bought it.
